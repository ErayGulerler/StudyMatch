# StudyMatch

StudyMatch connects students with compatible study partners or groups based on university, subject, availability, study level and preferred study style. Students can create profiles, search for study sessions, and join or leave groups.

A student app, admin panel and backend server communicate through a REST API, using simple rules to calculate matching scores.
